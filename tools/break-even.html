Break-Even Price Calculator

Find the exit price needed to cover entry and exit trading fees.

Enter values to calculate.

How it works

Long break-even = entry × (1 + fee) ÷ (1 − fee). Short break-even = entry × (1 − fee) ÷ (1 + fee). Fee is entered as a percentage and converted to a decimal.

Worked example

With an entry price of 100 USDT and a 0.05% fee per side, a long needs an exit near 100.10005 USDT to cover fees. A short needs an exit near 99.90005 USDT.

Assumptions

Assumes equal fee rates, fixed quantity and a linear USDT contract. Excludes funding, slippage and rebates. Actual break-even can differ if order fills use different maker or taker fees.

Find the price that covers modeled fees

Choose long or short, enter the entry price, and enter the same fee percentage assumed for each side. The result is a price, not an order. The calculator does not round it to an exchange tick size or include spread, slippage or funding.

Why not just add the fee twice?

The exit fee is charged on exit notional, so it changes with the exit price. For a long, solving exit − entry − fee × (entry + exit) = 0 gives entry × (1 + fee)/(1 − fee). Fee in this equation is the decimal rate: 0.05% becomes 0.0005.

Check the result with another tool

For hypothetical entry 100 and 0.05% fee per side, long break-even is approximately 100.100050025. Paste the unrounded result into the P&L calculator with the same direction and fee. Net P&L should be approximately zero for any positive quantity under the shared assumptions. Rounding the exit can leave a small residual.

What if maker and taker fees differ?

This calculator uses a single rate for both sides. It cannot represent different entry and exit rates exactly. For a linear long, the separate-rate expression is entry × (1 + entry fee)/(1 − exit fee); for a short it is entry × (1 − entry fee)/(1 + exit fee), using decimal rates.

A fee break-even price is not a safe stop price or guaranteed fill. Review stop execution limitations and model funding costs separately.
